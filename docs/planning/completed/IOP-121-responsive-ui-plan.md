## Changes and steps

1. Refine and translate the entire IOP-121 story into English, preserving its
   intent and separating the existing presentation slice from future data validation.
   Read dependencies IOP-116 and IOP-120 are already English: no translation needed.
   Their navigation and state-preview implementations are integrated into develop.
2. Adjust `apps/web/src/style.css` within the existing React/CSS presentation:
   wrapping text, compact tablet spacing, reachable controls with 44px minimum
   height and narrow reflow. Keep all scope, coverage and preview disclosures.
   No architecture, API, data, authentication, chart or filter implementation.
3. Add `apps/web/e2e/responsive.spec.ts` covering laptop 1366×768, tablet
   768×1024 and 1024×768 with touch, and 640×480 reflow (equivalent CSS viewport
   to a 1280×960 window at 200% zoom). Exercise all existing destinations and
   analytical states, retry/reset, keyboard navigation and orientation changes.
   Check page overflow and control bounds/size, including long source-like text.
4. Update `apps/web/README.md`, item/backlog and this record with actual evidence;
   move the finished presentation plan to completed and commit the bounded slice.
