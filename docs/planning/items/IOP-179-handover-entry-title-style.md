# IOP-179 — Distinguish entry titles from section headings

Status: Completed and published; local Docker activated. Owner screenshot feedback, 2026-09-29.

Give entry titles a different color and typographic emphasis from category headings
such as Safety everywhere `EntrySummaryCards` is used: Journal, Meeting preparation,
Daily overview and the meeting open-issues list. Use the existing blue link ink and
semibold weight for entry titles; keep section headings navy and bold. Preserve the
shared card layout, muted department labels and navigation.

This explicitly refines IOP-178's navy summary titles within the existing visual
identity and Accepted ADR-0032/0036 presentation boundaries.
