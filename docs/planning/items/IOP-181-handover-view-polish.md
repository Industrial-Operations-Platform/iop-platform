# IOP-181 — Refine operational selection, matrix and personal entries

Status: Completed and published; local Docker activated. Owner-requested visual refinement, 2026-09-30.

## Scope and acceptance

- Combine Start's duplicate metrics and view selectors into three colored selection
  cards with accurate counts and descriptions; refine the department selector.
- Give Department matrix a readable white surface, structured metadata and status
  badges. Align My entries with the shared operational summary cards.
- Preserve filtering, pagination, entry navigation, server-owned counts and state.
- Reuse the canonical identity; verify desktop/mobile layout and keyboard access.
  No API, business-rule or architecture changes.
