# IOP-182 — Structured entry details and neutral Start selection

Status: Completed and published; local Docker activated. Owner-requested UI refinement, 2026-09-30.

## Scope and acceptance

- Give entry details the visual hierarchy of My entries: location, state badges,
  equipment reference, full description, grouped follow-up fields and clear dates.
- Keep Start's three selection cards, counts and descriptions, using neutral
  surfaces with an unmistakable active selection instead of three semantic colors.
- Preserve actions, history, permissions, navigation and filters; verify desktop,
  mobile and keyboard behavior using the existing identity and architecture.
