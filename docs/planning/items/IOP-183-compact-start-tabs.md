# IOP-183 — Compact Start category tabs

Status: Completed. Owner-requested visual refinement, 2026-09-30.

## Scope and acceptance

- Replace the three oversized Start selection cards with compact, equal-width
  tabs filling the available row, with each category's total beside its label.
- Use standard text and small badges, with a clear active underline; remove the
  card descriptions and large figures. Keep all categories visible on mobile.
- Preserve collection selection, department filtering, counts, navigation and
  native keyboard operation through the shared presentation component.
