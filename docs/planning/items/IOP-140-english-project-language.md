# IOP-140 — English project language

## Status

Completed

## Goal and authorization

The user explicitly requested that all project development be in English,
regardless of the conversation language. Record this as a permanent rule.

## Scope

Add the language convention to AGENTS.md and link it from the planning workflow.
Cover authored code, identifiers, comments, documentation, plans, tests, default
UI messages and Git/PR descriptions. Preserve external data and deliberate
localization. Do not translate all historical documents in this task.

## Acceptance criteria

- [x] The permanent rule is clear and discoverable before future work.
- [x] Project content and conversation language are distinguished.
- [x] Historical content and external data are handled without corrupting meaning.
- [x] Links and documentation changes are verified; completion evidence recorded.

## Constraints, validation and non-goals

Follow ADR-0007. This is an authoring convention, not a programming-language or
product-localization decision. No code, mass translation or stack acceptance.
Check links and review wording against the explicit request.
