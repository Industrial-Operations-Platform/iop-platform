# IOP-180 — Polish operational summaries and shared visual hierarchy

Status: Completed; local review branch, not published. Owner-requested Start and Journal design refinement, 2026-09-29.

## Scope and acceptance

- Center the two Start summary cards, give both balanced explanatory content and
  restrained visual emphasis, and reuse shared metric components.
- Place Needs attention, Open reports and Shift Handover view selectors directly
  below the metrics. Show one bounded preview at a time with accurate counts,
  empty states and access to the full relevant list.
- Unify Start entry previews with Journal/Meeting cards. Emphasize department,
  state and relevant dates without overwhelming titles or inventing urgency.
- Replace the plain refresh/history actions with accessible, coherent controls.
- Document reusable roles and variants for future components; preserve the shared
  palette, typography, permissions and feature boundaries.
- Verify desktop/mobile layout, keyboard operation, refresh, selection, errors and
  entry/history navigation. No API, persistence or business-rule changes.
