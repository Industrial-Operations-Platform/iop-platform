# IOP-175 — Consistent handover detail heading

Status: Completed locally. Requested by the owner on 2026-09-29 after reviewing
the Shift Handover list and entry detail screenshots.

## Scope and acceptance

- Preserve the module heading typography, Operations label and description in detail.
- Display Shift Handover / Details with a keyboard-accessible module action that
  returns to the board and retains the selected department.
- Remove manual refresh controls from the handover heading and detail; preserve
  automatic loading after entry changes.
- Keep desktop/mobile layout usable and sidebar return navigation intact.

This supersedes the detail reload icon requested in
[IOP-174](IOP-174-handover-navigation-layout.md). Presentation-only work within
Accepted ADR-0032/0036; no API, domain or storage changes.
