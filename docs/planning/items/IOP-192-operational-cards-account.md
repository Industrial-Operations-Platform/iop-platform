# IOP-192 — Operational cards, account controls and entry notifications

Status: Completed

Owner request of 2026-10-02:

- Modernize the shared entry summary and use up to three responsive columns in
  Start's attention/open/highlight collections and My entries; retain full details.
- Use shared plus and search icons for New entry/Search history throughout Handover.
- Group account actions in a compact anchored dropdown inspired by the supplied
  images, keeping the visible name and avoiding background blur. Preserve profile
  editing, language selection, sign-out and authorized profile preview.
- Refine the platform icon while retaining the canonical IOP name and identity.
- Refine Department matrix surfaces, density and hierarchy while preserving the
  existing content alignment, column filters and keyboard scrolling.
- Add an in-app notification bell for new entries published by other people;
  the initial scope is Handover publications (including Start reports), with
  browser-local read state per account/site and automatic/manual refresh.
